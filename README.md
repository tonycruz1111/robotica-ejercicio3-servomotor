## 1. Título del ejercicio

**Ejercicio 2 — Control de LED mediante potenciómetro**

## 2. Descripción breve del circuito y su funcionamiento

En este ejercicio se utiliza un potenciómetro como entrada analógica para controlar el funcionamiento del LED.
El Arduino lee el valor producido por el potenciómetro a través de la entrada analógica A0.
El valor leído determina el tiempo que el LED permanece encendido y apagado mediante instrucciones de espera.
Al modificar la posición del potenciómetro, cambia el valor de la lectura y, por lo tanto, cambia el tiempo de funcionamiento del LED.

## 3. Componentes utilizados

* 1 placa Arduino Uno
* 1 potenciómetro
* 1 LED incorporado de la placa Arduino
* Cables de conexión
* Computadora para programar y simular el circuito en Tinkercad

## 4. Instrucciones de uso

1. Ingresar a Tinkercad y entrar en **Circuits**.
2. Abrir el proyecto mediante el enlace público de Tinkercad.
3. Para replicar el circuito, colocar una placa Arduino Uno y un potenciómetro.
4. Conectar la salida central del potenciómetro a la entrada analógica A0.
5. Conectar los extremos del potenciómetro a alimentación y tierra.
6. Iniciar la simulación.
7. Mover el control del potenciómetro y observar cómo cambia el tiempo de encendido y apagado del LED.
